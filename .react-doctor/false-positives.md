# React Doctor intentional exceptions

These suppressions are occurrence-level exceptions to React Doctor 0.9.13. Each one records the invariant that makes the flagged pattern safe; none disables a rule repository-wide.

| Location                                                           | Rule                                   | Invariant and evidence                                                                                                                                                                                                |
| ------------------------------------------------------------------ | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `components/FaviconSync.tsx`                                       | `effect-needs-cleanup`                 | The effect cancels both scheduled animation frames and invokes the optional color-store unsubscribe in its cleanup.                                                                                                   |
| `components/HomeProjectGrid.tsx`                                   | `nextjs-no-a-element`                  | `/resume.pdf` is a static document download/view, not an application route; ordinary anchor navigation is intentional.                                                                                                |
| `components/OverscrollIndicator.tsx`                               | `react-compiler-no-manual-memoization` | `ResizeObserver` subscribes to the callback by identity for the observer lifetime. The callback reads only refs and a stable state setter.                                                                            |
| `components/case-study-brochures/CaseStudyBrochureEditor.tsx`      | `set-state-in-effect`                  | Client-only local-storage hydration and debounced persistence intentionally update status/state after mount; server render cannot read browser storage.                                                               |
| `components/case-study-intake/CaseStudyIntake.tsx`                 | `set-state-in-effect`                  | Client-only local-storage hydration and persistence intentionally update state/status after mount; server render cannot read browser storage.                                                                         |
| `components/copy-editor/CopyEditor.tsx`                            | `set-state-in-effect`                  | Client-only local-storage hydration intentionally replaces the server-safe initial draft after mount.                                                                                                                 |
| `components/portfolio/PortfolioBrowser.tsx`                        | `set-state-in-effect`                  | The initial reveal is an async orchestration effect: fonts and media must resolve before its phase state can advance.                                                                                                 |
| `components/portfolio/PortfolioThemeProvider.tsx`                  | `set-state-in-effect`                  | Initial theme resolution depends on `matchMedia`, document data, and local storage, so it must synchronize after the client DOM exists.                                                                               |
| `components/case-study-brochures/CaseStudyBrochureEditor.tsx`      | `no-array-index-as-key`                | String-list entries have no persisted identity by design. Edits are controlled, and append/remove operations rewrite the complete ordered value array.                                                                |
| `components/copy-editor/CopyEditorEntrySlides.tsx`                 | `nextjs-no-img-element`                | This private authoring tool previews known local source assets and must accept every source format without Next Image loader constraints.                                                                             |
| `components/portfolio/presentation/usePortfolioProjectCarousel.ts` | `no-pass-live-state-to-parent`         | The Embla API registration writes to a ref-backed registry and unregisters in cleanup; it does not mirror render state. Backdrop notifications are imperative animation lifecycle events, not duplicated React state. |
| `tests/e2e/portfolio.spec.ts`                                      | `three-prefer-set-animation-loop`      | The animation frame is a bounded Playwright transform sampler and is cancelled by the test; it is not a Three.js renderer loop.                                                                                       |
