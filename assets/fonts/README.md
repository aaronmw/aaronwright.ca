# IBM Plex Mono

Regular and Bold TTFs from IBM’s official Plex distribution, bundled for local
Open Graph rendering. The existing browser font configuration is unchanged.

- [Regular](https://raw.githubusercontent.com/IBM/plex/master/packages/plex-mono/fonts/complete/ttf/IBMPlexMono-Regular.ttf)
- [Bold](https://raw.githubusercontent.com/IBM/plex/master/packages/plex-mono/fonts/complete/ttf/IBMPlexMono-Bold.ttf)
